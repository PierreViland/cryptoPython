### CryptoPython

Fichiers python permettant de réaliser du chiffrement AES et RSA ainsi que du hachage SHA. 

Objectif : comprendre son fonctionnement, commenter et réaliser un programme de test....


## Installation 

```sh
git clone https://github.com/PierreViland/cryptoPython.git
cd cryptoPython
pip install .
```

Pour le **développement** (les modifications du code sont prises en compte sans réinstaller) :

```sh
pip install -e .
```

### Vérifier l'installation

```sh
python3 -c "import cryptoPV; print(cryptoPV.__version__)"
```
